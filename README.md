Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers
Реализованные сценарии
Созданы автотесты для API, проверяющие создание, авторизацию пользователя, а также создание заказа

Процент покрытия 100% (отчет: htmlcov/index.html)

Структура проекта
data - пакет, содержащий данные для тестов
helpers - пакет, содержащий запросы API, шаги регистрации пользователя, получение токена, удаление пользователя
tests - пакет, содержащий тесты, разделенные по эндпоинтам
Запуск автотестов
Установка зависимостей

$ pip install -r requirements.txt

Запуск автотестов и создание HTML-отчета о покрытии

$ pytest --cov=praktikum --cov-report=html

Список тестов: 

test_user_creation.py:

создание уникального пользователя;
создание пользователя, который уже зарегистрирован;
создание пользователя и не заполнение одно из обязательных полей.

test_user_login.py:

вход под существующим пользователем;
вход с неверным логином и паролем.

Test_order_creation.py:

заказ с авторизацией;
заказ без авторизации;
заказ с ингредиентами;
заказ без ингредиентов;
заказ с неверным хешем ингредиентов.
